راهنمای ساده پنل ادمین
این بخش برای مسئول سیستم است؛ وقتی اطلاعات دیتابیس تغییر می‌کند، جدول جدید اضافه می‌شود، یا جواب‌های سیستم نیاز به بهتر شدن دارند از این قسمت استفاده می‌شود.
۱) اول دکمه خواندن اطلاعات دیتابیس را بزنید تا سیستم بفهمد چه جدول‌ها و ستون‌هایی داخل دیتابیس وجود دارد.
۲) بعد دکمه بررسی سلامت دیتابیس را بزنید تا مشخص شود اطلاعات برای استفاده آماده است یا مشکل جدی دارد.
۳) سپس دکمه ساخت سؤال تستی را بزنید تا سیستم خودش چند سؤال نمونه از روی جدول‌ها آماده کند.
۴) با دکمه اجرای سؤال‌های تستی بررسی کنید سیستم سؤال‌های ساخته‌شده را درست می‌فهمد یا نه.
۵) اگر سیستم معنی یک جدول یا ستون را اشتباه فهمید، از بخش اصلاح معنی توسط انسان استفاده کنید.
۶) در پایان دکمه به‌روزرسانی کامل سیستم را بزنید تا تغییرات جدید وارد سیستم شود.
نتیجه کارهایی که از پنل ادمین انجام می‌دهید اینجا نمایش داده می‌شود.
اصلاح معنی توسط انسان
نام جدول: نام جدولی که می‌خواهید معنی آن را به سیستم یاد بدهید. اگر نمی‌دانید نام دقیق جدول چیست، ابتدا «خواندن اطلاعات دیتابیس» را بزنید و از نتیجه آن استفاده کنید.
نام ستون: فقط وقتی پر شود که می‌خواهید معنی یک ستون خاص را اصلاح کنید. اگر خالی بماند، سیستم معنی کل جدول را اصلاح می‌کند.
عبارت فارسی: کلمه‌ای که کاربران معمولاً در سؤال‌هایشان می‌گویند. مثال: «پست»، «سمت»، «درخواست آموزشی»، «هزینه».
بعد از ثبت اصلاح، دوباره «بررسی سلامت دیتابیس» و سپس «به‌روزرسانی کامل سیستم» را اجرا کنید تا اصلاح جدید در پاسخ‌های سیستم اعمال شود.
